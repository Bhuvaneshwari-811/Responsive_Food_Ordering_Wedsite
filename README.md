# Foodie Express

## Project Description
Foodie Express is a responsive online food ordering and restaurant discovery website.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries
- Container Queries

## Features
- Responsive navigation bar
- Food categories
- Six restaurant cards
- Mobile, tablet and desktop layouts

## Testing
Tested using Chrome DevTools on mobile, tablet and desktop screen sizes.
